# Contributing

Keep instructions focused on preserving coding continuity. Open an issue with the host version, observed behavior, and a minimal example; remove credentials and private transcript content.

For changes, explain the observable improvement and run `python -m unittest discover -s tests -v`. Configuration helpers must preserve unrelated settings and create backups. Runtime claims need an implementation and evidence: a summary file alone does not demonstrate live compaction.

The skill uses progressive disclosure: core workflow in `SKILL.md`, integration detail in linked references. Keep names and descriptions precise and retain automatic skill discovery.
